5. Example: How the actual code works

Suppose a user selects Rewari from the Wix location search.

A. Frontend code – Wix Velo

JavaScript
const response = await fetch(
  "https://your-backend.com/api/environment?city=Rewari"

Here:

B. Backend code – Python FastAPI

Your backend receives the request and returns the processed result:

Python
from fastapi import FastAPI

app = FastAPI()

@app.get("/api/environment")
def get_environment(city: str):

# Illustrative sample result
return {

"aqi": 120,
"status": "Moderate"
